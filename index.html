Personal backup tool

MediaTracker Backups

MediaTracker is a private tracker for movies, TV shows, games and books. MediaTracker Backups is its companion tool for keeping recovery copies in the owner's Google Drive.

What it does

The tool uses rclone on the owner's server to upload backup archives, check uploaded copies and remove older backups according to the configured retention schedule. Backup files can also be downloaded for recovery.

Google Drive access

The owner connects their Google account through Google's authorization screen. The tool requests access to files it creates or files explicitly shared with it. It does not request access to the entire Drive.

This is a personal project with no public registration. This site provides information about the backup tool. The tracker itself is hosted separately.

Privacy and contact

Read the privacy policy for details about access, storage and deletion. For general questions, open an issue. For private requests, use the support email shown on the Google consent screen. Do not include passwords, tokens or backup contents in public issues.
