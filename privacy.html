Privacy policy

This policy covers the Google Drive integration used by MediaTracker Backups, a personal project maintained by TaigaForesters.

Information accessed

The integration requests the Google Drive drive.file permission. It can create files and access files created by or explicitly authorized for this app. It uses file names, identifiers, sizes, checksums and contents to store backups, verify copies, manage retention and restore data.

Backup archives may contain MediaTracker library entries, ratings, notes, tags, lists, history and account records. Recovery files may also include application configuration and keys. Treat downloaded archives as private.

How information is used

Access is used for backup and recovery. Google Drive data is not used for advertising, sold or used to train AI models.

Storage and access

Local backups and Google authorization tokens are stored on the owner's Oracle-hosted server. Remote backup copies are stored in the Google Drive account authorized by the owner. Google receives the files uploaded to Drive. Server administrators with access to the relevant files can access local backup material and authorization credentials.

Tokens allow scheduled backups without entering a Google password each time. The backup tool does not receive or store that password. This public information site contains no backup data or authorization tokens.

Retention and deletion

The intended retention is two daily backups and five monthly backups in each location. Automatic scheduling and pruning apply once backup setup is complete. Copies downloaded separately must be deleted separately.

The owner can stop scheduled backups, delete local and Drive backup files, and remove this app's access through Google Account connections. Revoking access stops future access but does not delete existing backups. Files moved to Drive Trash may remain there until permanently deleted.

Removing an entry from the live tracker does not immediately remove it from older backups. Those copies remain until they expire under retention or are deleted by the owner.

This website

These information pages use no analytics scripts, advertising or application cookies. GitHub Pages hosts the site and may process request information such as IP addresses under GitHub's privacy statement.

Contact and updates

For privacy or deletion requests, use the support email shown on the Google consent screen. General questions can be raised through the project's GitHub issues. Do not post personal records or credentials there. This policy will be updated when the integration's data handling changes.
